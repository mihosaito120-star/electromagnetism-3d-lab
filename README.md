# 電流と磁場 3Dラボ

右ねじの法則、ビオ＝サバールの法則、アンペールの法則の関係を、スマートフォン上で操作して学ぶための教材です。

## GitHub Pagesで公開

1. このフォルダをGitHubリポジトリの `main` ブランチへpushします。
2. リポジトリの **Settings → Pages** を開きます。
3. **Source** で **GitHub Actions** を選びます。
4. Actionsの公開処理が終わると、PagesのURLで教材を利用できます。

公開対象は `public/lesson` です。Blackboard Ultraには公開URLをWebリンクとして登録し、スマートフォンでは「新しいウィンドウで開く」設定を推奨します。
